# 課程架構｜兩天七小時

> 每天上午 9:00–12:30（3.5 小時）＝ 演講 1.5 小時 ＋ AI 實作 2 小時。
> 休息時間由講者視情況插入各段落中。

## 全課地圖

```
Day 1（3.5h）                          Day 2（3.5h）
├─ 演講 1.5h：川普為什麼課關稅          ├─ 演講 1.5h：美中攻防與版圖的未來
│   ① 川普要什麼                        │   ① 對中國怎麼出手
│   ② 工具怎麼選                        │   ② 版圖往哪走
│   ③ 誰付錢                            │   ③ 怎麼檢查一個說法
│   ④ 股市與匯率怎麼反應                │   ④ 帶走五樣東西
│                                        │
└─ 實作 2h：開工                        └─ 實作 2h：完工與報告
    ├─ 觀念與環境（六件套）                  ├─ 從 MEMORY 接手
    ├─ 拷問 → PLAN／TASK／MEMORY            ├─ 完成關卡三～五
    └─ 關卡一、二（抓、理）                  └─ 分組報告
```

## Day 1 實作段（120 分）

| 時段 | 分 | 內容 |
|---|---|---|
| 0:00–0:05 | 5 | 分組、抽題 |
| 0:05–0:15 | 10 | 核心觀念三頁：成果存倉庫才帶得走／三個檔案／動手前先拷問 |
| **0:15–0:45** | **30** | **環境建置（正式單元）**：裝 Python → 裝 Antigravity → Gmail 登入 → `pip install` → 連 GitHub → 跑出第一支程式 |
| 0:45–0:53 | 8 | 講者示範一次完整拷問流程 |
| 0:53–1:10 | 17 | 各組實作拷問 → 產出 `PLAN.md`、`TASK.md`、`MEMORY.md` |
| 1:10–1:50 | 40 | 實作關卡一、二；每過一關 commit 一次 |
| 1:50–2:00 | 10 | 收尾儀式：push ＋ 寫 `SETUP.md`／`requirements.txt` ＋ 在 MEMORY 寫「明天第一步」 |

**第一小時的過關條件**（五樣都有就過關）
1. 倉庫開好、組員都進得去
2. **環境跑得出第一支程式**
3. `PLAN.md` 六節齊全，存進倉庫
4. `TASK.md` 第一張寫好（目標、材料、驗收）
5. `MEMORY.md` 開檔，記下被 AI 問倒的洞

## Day 2 實作段（120 分）

| 時段 | 分 | 內容 |
|---|---|---|
| 0:00–0:12 | 12 | **照自己的 `SETUP.md` 重建環境**（文件驗收）＋ 從 `MEMORY.md` 接手 |
| 0:12–0:46 | 34 | 檢驗與修改：完成關卡三、四、五，用四判準自檢 |
| 0:46–0:48 | 2 | 換場、報告順序抽籤 |
| 0:48–2:00 | 72 | **分組報告**（每組 5–8 分鐘） |

## 五個關卡（每組都走同一副骨架，只換原料）

| 關卡 | 要交出什麼 | 怎麼算過 |
|---|---|---|
| **一、抓** | 用程式抓到原始資料，原封不動存檔 | 檔案存在、說得出網址與抓取時間 |
| **二、理** | 清洗與對齊：日期統一、數值可運算 | 隨機抽一天，數字對得上來源 |
| **三、看** | 畫圖，並標上至少 2 個關稅事件日 | 圖上事件日清楚可指 |
| **四、監控化** | 做成可重跑的工具，再執行一次會更新到最新 | 台上現場重跑一次 |
| **五、結論報告** | 讓 AI 讀你自己的資料，產出四節結論報告 | 每個數字都能在自己的資料裡指出來 |

> 走 EvoCode 路徑的組別，關卡一、二由平台內建報價取代，
> 關卡四改為「回測面板跑得動」。詳見 [`reference/EvoCode速查.md`](../reference/EvoCode速查.md)。

## 分組報告（每組 5–8 分鐘）

| 段 | 內容 |
|---|---|
| 題目與資料 | 抽到什麼、資料哪裡來 |
| 過程與困難 | 卡在哪（講真話——被限速、格式對不齊、AI 生的程式跑不動都算） |
| 解決辦法 | 怎麼繞過去的；**AI 哪裡講錯、你們怎麼發現的** |
| 目前成果 | **現場重跑一次工具** ＋ 展示結論報告 |
| 資料限制 | 這份資料哪裡不能信 |

> 素材不用現場編——`MEMORY.md` 打開就是。

## 評分構面

| 構面 | 權重 | 看什麼 |
|---|---|---|
| 過程與困難的真實度 | 30% | 講得出具體卡點，不是「一切順利」 |
| 解決方法 | 25% | 有自己的判斷，不是全程照抄 |
| 成果可重跑 | 25% | 台上重跑成功；失敗但能解釋原因也給分 |
| 資料限制與誠實度 | 20% | 說得出限制；用四判準自檢過 |
