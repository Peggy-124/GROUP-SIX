# 任務卡總覽｜五大類十題

> 十題規格詳見各題檔案。所有題目做的是「資料整理與輔助判讀工具」，
> 不推薦個股、不預測行情、不產生買賣指令——提到任何商品，一律是教學用途。

## 五個關卡對每組都一樣，只換原料

不論抽到哪一題，每一組交付的都是同一副骨架：

| 關卡 | 要交出什麼 |
|---|---|
| 一、抓 | 用程式抓到原始資料，原封不動存檔 |
| 二、理 | 清洗與對齊：日期統一、數值可運算 |
| 三、看 | 畫圖，並標上至少 2 個關稅事件日 |
| 四、監控化 | 做成可重跑的工具，再執行一次會更新到最新 |
| 五、結論報告 | 讓 AI 讀自己的資料，產出四節結論報告 |

不同的只是原料——每題的資料源、已知的坑、成果長相不一樣，但走的是同一條生產線。
五關卡與六件套的關係見 [`../docs/03-開發流程六件套.md`](../docs/03-開發流程六件套.md) 第五節；
第五關「結論報告」的四節格式見 [`../reference/結論報告格式.md`](../reference/結論報告格式.md)。

## 抽籤方式

課堂開場前 5 分鐘，各組抽籤決定題目：

- 若分組數為 7 組：每一類先抽 1 題，剩下的自由池 2 題再抽，優先開放題 1、3、5、6、7
  （這五題的資料源最穩定）。
- 若分組數為 8～10 組：十題全開，抽籤不重複，每組一題。
- 抽到題 9、10 的組別，走 Python 版或 EvoCode 版**由講師現場指派**——
  兩版難度相當，差別只在工具：Python 版自己抓資料算，EvoCode 版在群益 CTA 平台上
  用 C# 寫指標、用回測面板驗證。

抽完題目後，直接翻到對應的題目檔案開始讀。
