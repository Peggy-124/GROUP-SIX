# 題 9｜事件日反應統計指標

分類：輔助指標 ｜ 回 [任務總覽](README.md)

> **課堂框定**：這一類做的是「把討論出的規則寫成可重跑的指標工具」——訊號標在圖上
> 供人判讀，不推薦個股、不預測行情、不產生買賣指令。

## 目標

統計關稅事件日前後 N 日的報酬分布，做成「事件反應」指標卡。

## 成果形式

**工具**——輸入事件日清單，輸出前後 N 日平均報酬與方向一致率。

## 兩條實作路徑（任選其一，難度相當）

- **Python 版**：沿用題 3 或題 7 的資料源自己算，標訊號的圖＋指標卡，抽樣人工核對。
- **EvoCode 版**：在群益 CTA 用 C# 寫自訂指標，掛上圖表、用平台回測面板驗證，
  `.cs` 原始碼推進 GitHub 倉庫。教材見 [`../reference/EvoCode速查.md`](../reference/EvoCode速查.md)。

兩版都要走到「結論報告」這一關，合規框定相同。

## 資料源

沿用題 3 或題 7 的同源資料（證交所 `STOCK_DAY` 或 Yahoo 美股 chart，見
[`../reference/資料源速查.md`](../reference/資料源速查.md)）；事件日清單取自演講段的時間線。

## 驗收條件

1. 因子公式照講師模板實作（動手前先跟講師確認拿到虛擬碼模板）
2. 至少 4 個事件日入統計
3. 輸出一頁指標卡
4. 能口頭回答四判準的自檢（樣本少要怎麼說），見 [`../reference/四判準自檢.md`](../reference/四判準自檢.md)

## 已知坑

- 樣本少——結論的說法要降信心，這正是四判準第④條的活教材

## 延伸挑戰

改變 N（3／5／10 日）看結果穩不穩。
