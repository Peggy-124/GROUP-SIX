# 題 4｜證交所 OpenAPI 串接

分類：台股官方資料 ｜ 回 [任務總覽](README.md)

## 目標

用證交所官方 OpenAPI 抓一組盤後統計，做成自動更新的監控表。
抓哪一組資料由該組跟 AI 討論後寫進 `PLAN.md`。

## 成果形式

**工具**——重跑取回最新盤後統計，輸出表格＋簡單變化提示。

## 資料源

證交所 OpenAPI：
```
GET https://openapi.twse.com.tw/v1/exchangeReport/STOCK_DAY_ALL   （個股日成交資訊，全市場）
GET https://openapi.twse.com.tw/v1/exchangeReport/MI_INDEX        （大盤與各類股指數統計）
```
端點細節與坑見 [`../reference/資料源速查.md`](../reference/資料源速查.md) 第 2 節。

## 驗收條件

1. 能列出用了哪個 API 端點與欄位說明
2. 資料存檔、日期格式統一
3. 輸出表格可讀
4. 現場重跑成功

## 已知坑

- 欄位名稱是英文縮寫（如 `TradeVolume`＝成交股數、`TradeValue`＝成交金額），要對照文件
- 日期是民國年純數字（如 `1150814`），要自己轉西元
- 兩支端點都只給當日快照、沒有歷史查詢參數——要做歷史監控表，得每天各存一份、自己累積
- 官方 OpenAPI 目前查無三大法人買賣超端點

## 延伸挑戰

同時抓 `STOCK_DAY_ALL` 與 `MI_INDEX` 兩個資料集並對照——兩者欄位命名風格不同，
串接前要先看清楚文件。
