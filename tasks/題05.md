# 題 5｜期交所盤後資料爬蟲

分類：期貨與外匯 ｜ 回 [任務總覽](README.md)

## 目標

自動抓台指期每日行情（或三大法人期貨部位），做成盤後監控。

## 成果形式

**工具**——重跑補最新、輸出走勢圖＋最新值摘要。

## 資料源

期交所盤後資訊，POST 表單查詢：
```
POST https://www.taifex.com.tw/cht/3/futDailyMarketReport
Content-Type: application/x-www-form-urlencoded

queryType=2
marketCode=1
commodity_id=TX          # 台指期
queryDate=YYYY/MM/DD
```
端點細節與坑見 [`../reference/資料源速查.md`](../reference/資料源速查.md) 第 3 節。

## 驗收條件

1. 原始資料存檔、來源網址可指
2. 日期統一、數值可算
3. 圖上標至少 2 個關稅事件日
4. 現場重跑成功

## 已知坑

- 這是 POST 表單，不是 GET 網址，也沒有現成的 CSV／JSON API
- HTML 的 `<td>`／`<TD>` 標籤大小寫混用，正則要加 `IGNORECASE`，否則欄位會整排錯位
- 表格第一列才是近月契約，後面還有次月、季月等多筆
- 假日或國定假日無資料要跳過，不能假設每天都有
- 近月契約會換月（例如 202606 → 202608），直接串成連續序列會在換月日出現跳空
- 此頁的結算價與未沖銷契約量固定回傳 `-`，不是真的資料

## 延伸挑戰

把三大法人期貨部位另外串進來對照（注意：此查詢頁沒有日夜盤分欄，是盤後彙總資料）。
