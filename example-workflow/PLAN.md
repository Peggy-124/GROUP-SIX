# PLAN.md｜流程範例

> 這是 PLAN.md 六節的填寫示範，題目僅為舉例。各組題目另行公告。

## ① 目標

用三檔美股觀察一個問題：**同樣是半導體，為什麼有的公司在關稅時代大漲、有的幾乎沒動？**

標的：MU（美光，記憶體）、INTC（英特爾，處理器＋晶圓代工）、TXN（德州儀器，類比與嵌入式）。
挑這三檔的理由：它們分屬半導體的三個不同區塊，而且其中兩檔在課程的事件清單裡
直接被點名（英特爾被政府入股、美光宣布加碼投資），可以直接對照「宣布」與「發生」。

做完之後，看的人要能回答：這一年誰漲最多、關稅事件日前後三檔各自怎麼反應。

## ② 資料

- 來源：Yahoo chart 端點
  `https://query1.finance.yahoo.com/v8/finance/chart/{代號}?range=1y&interval=1d`
- 格式：JSON。`chart.result[0].timestamp` 是 UTC 秒數陣列，
  `chart.result[0].indicators.quote[0].close` 是對應的收盤價陣列。
- 事件日：`events.csv`（講師統一提供，六組共用，每筆都有出處）。
- **已知的坑**
  1. 這是非官方端點，格式可能被改，不保證永遠可用。
  2. `close` 陣列會有 `null`（停牌或最後一筆尚未收盤），不濾掉畫圖會斷線。
  3. timestamp 是 UTC，要轉成日期字串才能跟事件日比對。
  4. 三檔的交易日不完全一樣，要取交集才能對齊比較。

## ③ 功能清單（拆成五步，做完一步勾一步）

- [x] 抓三檔近一年日線，原始 JSON 原封不動存進 `raw/`
- [x] 整理成「日期 → 收盤價」，濾掉空值、UTC 轉日期
- [x] 三檔取共同交易日對齊
- [x] 畫圖：起點統一為 100，標上事件日
- [x] 輸出一頁摘要：期間漲跌 ＋ 事件日前後五日反應
- [x] 讓 AI 讀我們的摘要，產出結論報告

## ④ 驗收條件（可以核對的）

1. `raw/` 裡有三個 JSON 原始檔，檔名帶抓取日期。
2. 圖上有至少 2 個事件日標記（實際做出來有 6 個）。
3. 三檔起點都是 100，可以直接比較漲幅。
4. 重跑一次 `monitor.py`，摘要裡的「資料期間」會更新到最新交易日。
5. 結論報告裡的每個數字，都能在 `summary.md` 裡指出來源。

## ⑤ 除錯線索（跑失敗時先看這裡）

| 症狀 | 先檢查 |
|---|---|
| `KeyError: 'timestamp'` | 代號打錯，Yahoo 回傳的 result 是空的 |
| 畫出來的線中間斷掉 | `close` 的 `null` 沒濾掉 |
| 事件線沒出現在圖上 | 事件日超出資料範圍（近一年只到去年同期） |
| 中文變成方框 | 字型沒設定，見 `monitor.py` 開頭的字型區塊 |
| 三檔天數對不上 | 沒取交集，直接用了各自的日期陣列 |

## ⑥ 維護方式

- **重跑**：`python -X utf8 monitor.py`，會自動抓到最新交易日並覆蓋圖與摘要。
- **換標的**：只改 `monitor.py` 最上面的 `TICKERS` 與 `TITLE` 兩行，其他都不用動。
- **加事件**：在 `events.csv` 加一列（日期、標籤、出處），圖與摘要會自動納入。
- **資料源掛掉時**：Yahoo 端點若改格式，先用瀏覽器直接開那個網址看回傳長什麼樣，
  再調整 `to_series()` 的解析路徑。
