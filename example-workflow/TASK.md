## TASK 5：產出結論報告　✅ 已完成

```
目標：讀我們工具的最新輸出，產出一頁結論報告

材料：
  1. summary.md 全文（期間漲跌表 ＋ 事件日前後五日反應表）
  2. PLAN.md 第①節（我們想回答的問題）
  3. 演講段的四判準：時間順序／別的原因／換對象／只發生一次

驗收：
  1. 四節齊全：現況數字、與事件日對照、判讀、限制與失效條件
  2. 每個數字都能在 summary.md 裡找到，不可以出現我們資料裡沒有的數字
  3. 第④節不可以空白，要具體寫出「哪裡不能信」
  4. 不出現買賣建議、目標價、漲跌預測
```

**驗收結果**：第一版不通過——它寫「關稅推升記憶體需求，帶動美光大漲 703%」，
但我們資料裡美光在六個事件中有三次是下跌的，這句因果站不住。
要求改成描述句並補上「主因是 AI 記憶體需求，不是關稅」後通過。

## TASK 2：整理成可以用的格式　✅ 已完成

```
目標：把 Yahoo 的巢狀 JSON 整理成「日期 → 收盤價」

材料：
  1. raw/ 裡的三個原始 JSON
  2. 結構：chart.result[0].timestamp（UTC 秒數）
           chart.result[0].indicators.quote[0].close（收盤價）
  3. 坑：close 裡會有 null；timestamp 是 UTC 要轉日期

驗收：
  1. 輸出是 {日期字串: 收盤價} 的形式
  2. 沒有 null 混在裡面
  3. 三檔取共同交易日之後，天數一致
```

**驗收結果**：AI 第一版沒處理 null，畫圖時線會斷。把坑貼給它才補上。
