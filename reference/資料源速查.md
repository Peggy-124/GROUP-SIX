# 資料源速查｜六個資料源

> 六個資料源、各自的用途、端點、回傳格式與已知坑，統整自課前實測結果。
> 探測腳本與樣本檔案在 [`../probes/`](../probes/)，可以直接參考改寫。
> 任一資料源當天連不上，先跟講師拿備援檔起步，課後再自己重抓。

---

## 1. 證交所 STOCK_DAY（個股日成交）

**用途**：抓個股或 ETF 的歷史日線（開高低收、成交量）。

**端點**：
```
https://www.twse.com.tw/exchangeReport/STOCK_DAY?response=json&date=YYYYMMDD&stockNo=2330
```
`date` 只要是該月任一天即可，`stockNo` 換成想抓的證券代號（例如 `0050`）。

**回傳格式**：JSON，`data` 為二維陣列，欄位順序見同一份回應裡的 `fields`：
日期／成交股數／成交金額／開盤價／最高價／最低價／收盤價／漲跌價差／成交筆數／註記。

**已知坑**：
1. **一次只回一個月**，要抓一整年得跑 12 次。
2. **日期是民國年格式**（如 `114/07/01`），要自己轉西元。
3. 數字欄位有千分位逗號，要清除才能轉成數值。
4. 有隱性限速，連續抓取要加延遲（每次 1–2 秒）。

**對應題號**：題 3、9、10。

## 2. 證交所 OpenAPI（openapi.twse.com.tw）

**用途**：抓當日全市場的個股資訊或大盤指數統計，不用逐檔查詢。

**端點**：
```
GET https://openapi.twse.com.tw/v1/exchangeReport/STOCK_DAY_ALL   （個股日成交資訊，全市場約 1300+ 檔）
GET https://openapi.twse.com.tw/v1/exchangeReport/MI_INDEX        （大盤與各類股指數統計，約 260+ 種指數）
```

**回傳格式**：JSON 陣列。`STOCK_DAY_ALL` 欄位為英文縮寫
（`Date`／`Code`／`Name`／`TradeVolume`／`TradeValue`／`OpeningPrice`／`HighestPrice`／
`LowestPrice`／`ClosingPrice`／`Change`／`Transaction`）；`MI_INDEX` 欄位為中文
（日期／指數／收盤指數／漲跌／漲跌點數／漲跌百分比／特殊處理註記）。

**已知坑**：
1. **欄位名稱是英文縮寫**，要對照文件才知道對應到什麼（`TradeVolume` 是成交股數，
   `TradeValue` 是成交金額，容易搞混）。
2. **日期是民國年純數字字串**（如 `"1150814"`），要自己轉西元、切年月日。
3. **這兩個端點都只回傳「當日」一筆快照**，沒有 start/end 日期參數；要做歷史監控表，
   得每天各存一份、自己累積歷史，不能像 `STOCK_DAY` 那樣一次查一個月。
4. 官方 OpenAPI 目前查無三大法人買賣超端點。
5. 建議加上 User-Agent 標頭，沒有寫有時會被視為異常流量。

**對應題號**：題 4。

## 3. 期交所盤後資訊（每日行情）

**用途**：抓期貨（如台指期）每日的盤後行情。

**端點**：這是一個查詢頁面，用 POST 帶查詢參數，不是單純的 GET 網址：
```
POST https://www.taifex.com.tw/cht/3/futDailyMarketReport
Content-Type: application/x-www-form-urlencoded

queryType=2
marketCode=1
commodity_id=TX          # 台指期，可換其他契約代碼
queryDate=YYYY/MM/DD
```

**回傳格式**：整頁 HTML，資料在其中一個 `<table>` 內，沒有現成的 CSV／JSON 下載連結。
欄位（依表格順序）：契約／到期月份(週別)／開盤價／最高價／最低價／最後成交價／
漲跌價／漲跌%／成交量／結算價／未沖銷契約量／最佳買價／最佳賣價／歷史最高價／歷史最低價。

**已知坑**：
1. **這是表單 POST**，要用程式送 POST body，不能直接 GET 網址。
2. **HTML 標籤大小寫混用**：同一份 HTML 裡 `<td>` 與 `<TD>` 混用，用正則解析一定要加
   `IGNORECASE`，否則後面欄位會整排錯位。
3. **表格第一列是「近月契約」**，後面還有次月、季月等多筆，抓資料前要先確認要哪一列。
4. **假日或國定假日無資料**，回傳頁面沒有資料表格，程式要判斷「查無資料」並跳過。
5. **此頁「結算價」「未沖銷契約量」固定回傳 `-`**，不是真的資料，要拿到這兩欄需另外
   找期交所別的報表頁面。
6. **近月契約會換月**（例如 202606 → 202608），直接串成連續價格序列會在換月日出現跳空，
   要自己處理換月或固定只取單一月份契約。

**對應題號**：題 5。

## 4. Google News RSS

**用途**：查關鍵字相關新聞，整理成時間軸或摘要。

**端點**：
```
https://news.google.com/rss/search?q=<關鍵字，URL-encode>&hl=zh-TW&gl=TW&ceid=TW:zh-Hant
```

**回傳格式**：標準 RSS 2.0 XML，`<item>` 內含 `title`、`link`、`pubDate`、`source`，
UTF-8 編碼，中文無亂碼。單次查詢固定回傳約 100 筆。

**已知坑**：
1. **link 是 Google 轉址網址**，不是原始新聞網址，開啟後才會跳轉到真正來源；
   直接存的話，日後原站若下架連結仍可能失效。
2. **標題重複**：同一事件被多家媒體報導，標題高度相似或完全相同，需要用標題模糊比對
   或連結去重。
3. **pubDate 是 UTC 時間**，不是台北時間，畫時間軸前要 +8 小時。
4. **關鍵字組合影響很大**：空白代表 AND，加引號代表精準片語，結果差很多，
   建議在 `PLAN.md` 記錄關鍵字怎麼選、為什麼。
5. 沒有分頁機制，一次查詢就是全部結果，抓不到「更舊」的新聞，只能靠關鍵字或時間詞
   （如加 `after:2026-08-01`）調整範圍。

**對應題號**：題 1、2。

## 5. Yahoo 美股 chart 端點

**用途**：抓美股個股或外匯的歷史日線。

**端點**：
```
https://query1.finance.yahoo.com/v8/finance/chart/<代號>?range=1y&interval=1d
```
股票代號直接用代碼（如 `NVDA`），外匯代號用 `<幣別>=X`（如 `JPY=X` 代表 USD/JPY）。

**回傳格式**：JSON，`chart.result[0]` 內含 `meta`（含 `longName` 名稱）、
`timestamp`（Unix 秒數陣列，UTC）、`indicators.quote[0]` 下的 `open`／`high`／`low`／`close`／
`volume`。

**已知坑**：
1. **非官方端點**，沒有正式公開文件保證長期穩定，格式未來可能變。
2. **時區用 UTC timestamp 自己換算**，不要直接信任回傳裡 `meta` 顯示的時區名稱
   （外匯資料的時區欄位有時顯示的地區跟報價來源無關）。
3. 美股收盤日期與台灣時間有時差認知問題，串接台股資料前要弄清楚拿到的是美國當地哪一天。
4. 外匯資料**只有開高低收（中價），沒有買入／賣出雙向報價**，如果題目需要買賣雙價，
   這個端點無法提供。

**對應題號**：題 7、8、9、10。

## 6. 群益交易王 CTA（外匯與指數）

**用途**：取得外匯與海外指數的即時／歷史報價，或在平台上用 EvoCode（C#）寫自訂指標。

**取得方式**：不是網路 API 端點，而是安裝群益交易王電腦版軟體（安裝步驟見
[`../docs/02-環境設定.md`](../docs/02-環境設定.md)④），用模擬帳號登入後在軟體介面裡
掛商品圖表，或在 EvoCode 開發環境裡透過 `HistoryDataSeries`／`InstrumentsManager` 等
API 存取報價（見 [`EvoCode速查.md`](EvoCode速查.md)）。

**回傳格式**：平台圖表報價（可另存為資料檔）或 EvoCode 指標讀到的數值序列，
沒有固定的 JSON／CSV 規格，依平台介面操作為主。

**已知坑**：
1. **CFD 報價有買價／賣價價差（spread）**，用哪一個要在報告裡寫清楚。
2. **各商品交易時間不同**，恆生指數與其他海外指數的時段差很多，動手前先確認。
3. **模擬帳號需先申請並收信取得帳號**，申請流程見
   [`../docs/01-開課前準備.md`](../docs/01-開課前準備.md)，務必課前辦好。
4. **沒有新台幣（TWD）貨幣對、沒有美元指數（DXY）、沒有費城半導體指數（SOX）**，
   詳見 [`../tasks/題06.md`](../tasks/題06.md) 的三個缺口說明。

**對應題號**：題 6（含題 9、10 選擇 EvoCode 路徑的組別）。

## 7. 新台幣匯率與美元指數（公開資料源）

**用途**：群益 CTA 平台沒有新台幣貨幣對，也沒有美元指數。要看這兩個，用這裡的公開來源。
對應題號：題 6 的補充；也是演講段提到台幣急升與美元走弱時，可以自己去驗證的地方。

**端點**：Yahoo chart 端點（與第 5 節同一套寫法，只是換代號）

```
https://query1.finance.yahoo.com/v8/finance/chart/{代號}?range=1y&interval=1d
```

| 代號 | 內容 | 實測（2026-08-17） |
|---|---|---|
| `TWD=X` | 美元兌新台幣 | ✅ 近一年 263 筆 |
| `^NYICDX` | ICE 美元指數 | ✅ 近一年 251 筆，**無空值，優先用這個** |
| `DX-Y.NYB` | 同一個美元指數的另一個代號 | ⚠️ 可用但有 52 個空值，不建議 |
| `JPY=X`／`KRW=X` | 美元兌日圓／韓元 | ✅ 各 263 筆，可作對照 |

**已知坑**
1. **只有中價**，沒有買入／賣出雙向報價——報告要寫明用的是中價。
2. 非官方端點，格式可能被改，不要假設永遠可用。
3. **最後一筆常是當下的即時快照**，不是完整交易日，畫圖前先判斷要不要剔除。
4. 台灣銀行牌告匯率（`rate.bot.com.tw`）會被機器人偵測攔下，需要瀏覽器執行
   JavaScript 才能通過。本課程不繞過這類保護機制，因此不列為可用路徑；
   若一定要用台銀的雙向報價，請自行到網站上手動下載。

**現成腳本**：[`../probes/probe-fx.py`](../probes/probe-fx.py)（四個代號一次抓完，輸出到 `probes/output/`）
