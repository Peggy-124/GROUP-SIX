# 匯率與出口股連動｜多幣別 AI 股票研究工具

本專案為專業級金融資料工程與量化研究工具，專注於分析**美元指數（^NYICDX）**、**美元兌台幣（USD/TWD, TWD=X）**、**美元兌日圓（USD/JPY, JPY=X）**、**美元兌人民幣（USD/CNY, CNY=X / USD/CNH）**與台灣主要出口族群（半導體、電子代工、航運、自行車）之間的連動關係。

---

## 🎯 核心功能

1. **多幣別與指數行情追蹤**：
   - 包含 ICE 美元指數（`^NYICDX`）、`TWD=X`、`JPY=X`、`CNY=X`、`CNH=X`。
   - 正確處理 `USD/XXX` 報價方向（數值上升 = 美元升值、當地幣貶值）。
2. **台灣四大出口族群等權重指數**：
   - **半導體**：台積電 (2330)、聯發科 (2454)、聯電 (2303)
   - **電子代工 (EMS)**：鴻海 (2317)、廣達 (2382)、緯創 (3231)
   - **航運**：長榮 (2603)、陽明 (2609)、萬海 (2615)
   - **自行車**：巨大 (9921)、美利達 (9914)
   - **自訂與彈性管理**：支援在 UI 介面上隨時新增/刪除個股與建立新族群。
3. **量化指標與視覺化**：
   - **基期 100 標準化走勢**（跨資產同圖對照）
   - **5 日、20 日與區間總累積報酬率**
   - **Pearson 相關係數熱圖**（日報酬標準量化模型）
   - **20 日動態滾動相關係數**（捕捉政經政策轉折點）
   - **領先落後交叉相關性分析**（檢驗匯率平移 $\pm 1, \pm 3, \pm 5, \pm 10$ 交易日之領先效應）
   - **關稅重大事件研究 (Event Study)**（事件日前後 $\pm 5$ 交易日窗口報酬統計）
4. **AI 智慧四節研究結論報告**：
   - 嚴格遵守成大課程四節規範（① 現況數字、② 與關稅事件日對照、③ 判讀、④ 限制與失效條件），無數據幻覺。
5. **資料備援與匯出**：
   - 原始資料存檔至 `raw/`，清洗對齊資料存檔至 `data/`。
   - 具備 3 次自動重試與離線本機快取備援。
   - 一鍵匯出 Markdown 研究報告、對齊行情 CSV、族群指數 CSV 與事件研究 CSV。

## 📁 專案檔案結構

```
AI-4-main/
├── app.py                 # Streamlit 主儀表板應用程式
├── config.py              # 系統設定（標的、族群、預設事件、路徑）
├── data_fetcher.py        # 資料抓取模組（Yahoo Finance Chart API、重試、快取）
├── data_processor.py      # 資料清洗、對齊、等權重計算、相關係數、事件研究
├── visualizer.py          # Plotly 互動式圖表模組
├── ai_engine.py           # AI 結構化研究報告生成引擎
├── events.csv             # 預設重大關稅與政策事件清單
├── requirements.txt       # Python 相依套件清單
├── run.bat                # Windows 一鍵啟動指令檔
├── raw/                   # 原始行情 JSON / CSV 存檔目錄
└── data/                  # 清洗與對齊後之 CSV 輸出目錄
```

## 🚀 快速啟動

### 1. 安裝套件
```bash
pip install -r requirements.txt
```

### 2. 啟動 Streamlit 介面
```bash
streamlit run app.py
```
或在 Windows 環境直接雙擊執行 `run.bat`。
